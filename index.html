achievements
  • Security Audits
    NOTICE: THESE AUDITS WERE ALL DONE WITH PERMISSION FROM THE DEVELOPERS OF THE WEBSITES.
    Github repo of writeups on vulnerabilities can be found at Cybersec Repo.

    Performed security audit on my friend's website (which he asked to keep anonymous). Click for total findings:
    • Python interpreter had a misconfigured Docker and gave every user root permissions, allowing me to mount it and gain RCE.
    • Path to admin panel which was /admin/api/${userId} (I do not remember the exact variable name) trusted the client's request without proper authentication,
      allowing me to access the admin panel by simply changing the request.
    • No rate limiting on all endpoints like /login, /register, /projects and more, meaning many endpoints were vulnerable to a DoS.

    Performed security audit on my teacher's website, that just belongs to my teacher as an individual not the school's website. (anonymous because I haven't asked if I can actually put the website publicly) Click for total findings:
    • Swagger UI of the website was exposed.
    • Multiple endpoints like /users/profile, /auth/login had a lack of rate-limiting, making them vulnerable to a potential DoS via resource exhaustion.
    • Prompt injection in a quiz question translation feature, allowing the AI translator to solve questions for you, and passing a large prompt could potentially slow the website down or even cause a DoS.
    • Time taken for a question (this website contained quizzes) is passed by the client, allowing users to put 1 second in a modified request and the website would trust it.
